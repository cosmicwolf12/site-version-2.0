# AeroView

Веб-панель для просмотра, фильтрации и загрузки видеозаписей с дронов. Интерфейс обслуживает Node.js, REST API работает на FastAPI; загруженные файлы и метаданные сохраняются локально.

## Запуск в Windows

1. Установите Python 3.10+ и Node.js 18+.
2. Дважды щёлкните `setup.bat` — он создаст локальное окружение Python и установит зависимости FastAPI, PyTorch и YOLO.
3. Запустите `start.bat`. Node.js откроет сайт по адресу <http://localhost:3000> и автоматически запустит API.

Для запуска из терминала используйте `npm.cmd start`. Если вы меняли Python-зависимости, повторно выполните `setup.bat`.

## Возможности

- Поиск, фильтрация по статусу, дрону и периоду, несколько вариантов сортировки.
- Постраничный каталог, карточки со статусом обработки и деталями записи.
- Загрузка видео MP4, MOV и AVI (до 10 ГБ на файл) с отображением прогресса.
- FastAPI API: `/api/health`, `/api/videos`, `/api/videos/upload`, `/api/videos/{id}/frames` и `/api/videos/{id}/frames/{frame_index}/image`. Описание API доступно в Swagger UI по адресу <http://localhost:8000/docs>.
- `best.pt` — модель YOLOv8 для обнаружения объектов класса `waste`. Загруженные видео обрабатываются на CPU в фоне; на каждые 0,25 секунды видео сохраняется JPEG-кадр с рамками объектов и координатами детекций.
- Видео сохраняются в `backend/data/uploads/`, кадры — в `backend/data/frames/<id-видео>/`, результаты детекции и SQLite-база — в `backend/data/`.

По умолчанию модель работает на CPU, поэтому скорость обработки зависит от длительности видео и характеристик компьютера. Если настроена CUDA-совместимая сборка PyTorch и доступна видеокарта NVIDIA, для неё можно задать `AEROVIEW_DEVICE=0` перед запуском `start.bat`.

Образцы библиотеки демонстрационные. Для ваших видеозаписей сайт запускает локальный конвейер компьютерного зрения на модели `best.pt`; оригинал видео и обработанные кадры доступны отдельно.
